# School modular kit — original authoring source

`SchoolKit.blend` is generated by `tools/blender/env_kit_schoolbasement.py`.
No downloaded geometry, images, fonts or other asset inputs are used. There are
no external textures or procedural shader dependencies: relief, edge bevels,
surface colour variation, cracks, stains and chalk marks are mesh geometry.

## Rebuild and validate

From this worktree's root (not the open main checkout):

    "C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" --background --factory-startup --python-exit-code 1 --python tools/blender/env_kit_schoolbasement.py -- --theme school
    "C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" --background --factory-startup --python-exit-code 1 --python tools/blender/validate_env_kit_schoolbasement.py -- --theme school

Use `--theme all` for both kits. `--skip-previews` is an optional regeneration
shortcut, not a complete fresh preview verification. The source contains hidden
original meshes at the origin and a linked-mesh, cutaway review room. Unhide the
originals to edit; review cameras, lights and room instances never enter FBX.
`Logs/AgentValidation/Art/EnvSchool/` holds front and three-quarter PNGs plus
validator text/JSON. Image content checks are not owner artistic acceptance.

## Placement and import contract

All dimensions below are metres in exported Unity XYZ: Y up, interior -Z.
Blender source coordinates are `(X, -Z, Y)`. FBX uses forward -Z, up Y,
`bake_space_transform=True`, unit scale 1 and applied mesh transforms.
Unity import must use `bakeAxisConversion=false`. Do not apply another 90-degree
rotation to the already baked FBX vertices. No collider is embedded.

- Straight walls: bottom-centre of wall plane at origin, width 2, height 3.8.
  Core occupies Z=0..0.25. Interior relief reaches Z=-0.054. Edge vertices stay
  exactly on X=+/-1 with matching height cuts 0, 1.1, 2.8 and 3.8.
- Door: width 4, clear aperture X=-1.6..1.6, Y=0..2.8. No door leaf is included.
- Window: clear structural opening width 1.3, Y=1.1..2.8; metal mullions remain.
- Arc: radius is the interior radius (4, 6 or 8), not the outer radius or a
  bounding-box half-width. Sweep is 30, 20 or 15 degrees respectively; radial
  shell is 0.25 thick. Pivot is the bottom midpoint of the tangent wall plane.
  Local circle centre is `(0,0,-R)`. Interior points are
  `(R*sin(a), y, R*cos(a)-R)` for `a` between +/- half the sweep.
  Place adjacent copies about the same circle centre, rotating by the sweep;
  do NOT translate arcs by exactly 2m or normalize their bounding widths to 2m.
- Corner in/out: 0.5-wide L-shaped returns; wall-plane pivot, height 3.8.
- Pillar: bottom-centre, 0.48 square base/capital, full theme height.
- Floor: 2x2, bottom-centre, height 0.1002. To put its walking surface at Y=0,
  place its pivot at Y=-0.1002. Keep runtime collision on the smooth structural
  slab; the hairline crack is visual only.
- Ceiling: 2x2, bottom-centre, height 0.13; lowest sagged panel is at local Y=0.
  Place the pivot at the theme ceiling height. Open review ceilings are a
  cutaway convention, not a missing kit piece.
- Trim: width 2, height 0.18, depth 0.07, bottom-centre in X/Z.
- Props: bottom-centre in X/Z, face -Z. Chalkboard height is its own frame
  height; mount the whole object above the floor as desired.

Manifest sizes are actual bounding boxes including relief, not nominal module
spacing. `SchoolKit.manifest.json` has only the coordinator's shared fields.
The validator independently checks both fixed contract and provisional sizes.

## Provisional authoring values (not runtime configuration)

All defaults are in `env_kit_schoolbasement.py`; no Unity tunables are added.
`HEIGHT` holds the required 3.8m height, not a provisional value.

- `wall`: 0.25 core depth; four 1.04m-high wainscot panels, 0.014m joints,
  0.018m edge setback, 0.048m relief, 0.007m bevel; 0.04m metal cap band.
  Four small asymmetric grime polygons stay above the door aperture.
- `arc`: eight angular subdivisions, four vertical cuts. `architecture`:
  pillar body 0.34 square, capitals 0.48 square x 0.20 high, bevel 0.015;
  corners and floor/ceiling/trim extents are listed above; tile bevel 0.006.
- `school_prop`: desk 1.12 x 0.755162 x 0.65, chair
  0.43 x 0.891366 x 0.432938, three-locker bank 1.2 x 1.86 x 0.479,
  chalkboard 1.8 x 1.38 x 0.1945. Desktop bevel 0.018, seat bevel 0.015,
  frame/locker bevels 0.006..0.018. Tubes use 12 sides and radii
  0.012..0.025; chalkboard has 18 seeded chalk fragments.
- `PALETTES['school']`, linear RGB: plaster (0.42,0.40,0.30), tile
  (0.19,0.28,0.22), tile_worn (0.24,0.31,0.24), metal (0.10,0.15,0.14),
  wood (0.26,0.13,0.055), chalk (0.58,0.61,0.48), board
  (0.022,0.052,0.038), grime (0.12,0.13,0.085), floor (0.27,0.25,0.18),
  glass (0.095,0.15,0.16; reserved, not assigned). Alpha 1; metal metallic
  0.65/roughness 0.58, all other surfaces metallic 0/roughness 0.82.
- `Piece`: isolated random seed `<theme>/<piece>/20260930`; no clock or global
  random state. Explicit mesh coordinates within each builder are authored
  shapes, not gameplay tunables.
- `render_previews`: Cycles 24 samples, seed 260930, denoising on, 1200x800;
  orthographic scale 16.5. Cameras at (1.5,5.7,-14) and (11,8,-13), aimed at
  (1.5,1.3,0.6). World RGB (0.07,0.085,0.10), strength 0.35.
  Area lights: (-2,5,-4), 1500W, RGB (1,0.77,0.50), size 5;
  (3,5,1), 1200W, RGB (0.60,0.76,1), size 4;
  (0,2,-2), 350W, RGB (1,0.9,0.72), size 3. These are inspection lighting,
  not the game's final darkness/fog/torch settings.
- Validator: dimension tolerance 0.01m; pivot/seam/source tolerance 0.00002m;
  architectural budget 300, service/prop budget 1500 triangles.

## Integration boundary

Coordinator owns Unity import, generated `.meta` files, URP material remapping,
kit registration, collision/navigation and per-piece/whole-kit primitive fallback.
Keep the material slot names `school_<surface>` exactly. Re-run setup twice and
check absence of duplicate geometry/materials, clear doorways and arc seams.
Nothing in this art task edits or tests the live procedural generation path.
FBX/Blend binary timestamps may differ between generations; manifest byte hashes
and re-imported geometry/material signatures are the determinism evidence.
