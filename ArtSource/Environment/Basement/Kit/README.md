# Basement modular kit — original authoring source

`BasementKit.blend` is generated by `tools/blender/env_kit_schoolbasement.py`.
No downloaded assets or external textures. Concrete relief, stains, bent service
silhouettes, duct dents, seams, rusty collars and the boiler gauge are geometry.
The named originals are hidden at the origin; the review room uses linked mesh
instances. Only originals are selected for the one-piece-per-FBX export.

From this worktree's root:

    "C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" --background --factory-startup --python-exit-code 1 --python tools/blender/env_kit_schoolbasement.py -- --theme basement
    "C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" --background --factory-startup --python-exit-code 1 --python tools/blender/validate_env_kit_schoolbasement.py -- --theme basement

Previews and validation reports: `Logs/AgentValidation/Art/EnvBasement/`.
Use `--theme all` for both themes. Generation uses only local Blender 5.2.

## Shared placement contract

See [School kit authoring notes](../../School/Kit/README.md) for axis conversion,
wall-plane pivots, arc placement formula, source editing, floor/ceiling offsets,
common geometry sizes, preview defaults and the Unity integration boundary.
Basement wall/corner/pillar height is 3.2m, with vertical cuts 0, 1.1, 2.8, 3.2.
Door opening remains 3.2m wide by 2.8m high. Other architectural dimensions match
School; they are not automatically scaled by the theme height.

All sizes below are exported X/Y/Z metres. Service runs lie along X, not along
the facing axis. End ports are capped (opaque modular visual parts, not a fluid
simulation). End collars hide mating joins. Bottom-centre pivots include collars.

| Piece | Bounds X/Y/Z | Port centres and direction, relative to bottom-centre pivot |
| --- | --- | --- |
| pipe_straight_2m | 2 / 0.32 / 0.32 | (-1,0.16,0), (1,0.16,0); X |
| pipe_elbow | 0.79 / 0.32 / 0.79 | (-0.395,0.16,-0.235), (0.235,0.16,0.395); -X, +Z |
| pipe_tee | 1.2 / 0.32 / 0.76 | (-0.6,0.16,-0.22), (0.6,0.16,-0.22), (0,0.16,0.38); -X, +X, +Z |
| duct_straight_2m | 2 / 0.56 / 0.72 | (-1,0.28,0), (1,0.28,0); X |
| duct_elbow | 1.24 / 0.56 / 1.24 | (-0.62,0.28,-0.26), (0.26,0.28,0.62); -X, +Z |
| prop_valve_wheel | 0.57 / 0.57 / 0.215 | Face -Z; stem toward +Z; wheel is in XY |
| prop_boiler | 1.15 / 2.32 / 1.37 | Face -Z; gauge and wheel face the room |

Manifest bounds include fittings, so they are NOT the pipe bore diameter or the
bend radius. Service ports need the explicit offsets above, not bounds-centred
placement. Straight pipe ends are at +/-1 even though their collars are 0.12m
long. Arc bounding widths exceed the nominal approximately-2m interior chord.

## Provisional authoring values

- `basement_prop` in `env_kit_schoolbasement.py`: pipe bore visual radius 0.12,
  collars radius 0.16, straight bands radius 0.135; 12-sided cylinders. Elbow
  centreline radius 0.55 with eight bend spans; tee branch length 0.6.
- Duct body section 0.66 wide x 0.50 high, collars 0.72 x 0.56, 0.06 long;
  body bevel 0.025, collar bevel 0.008. Duct bend centreline radius 0.85 with
  six bend spans and exact axial end sections. Dent rise 0.01.
- `valve`: wheel major radius 0.26 (boiler wheel 0.17), rim radius 0.025,
  16 major x 6 minor segments; four 0.017-radius spokes, stem radius 0.043
  and length 0.215. Wheel bounds 0.57 include rim, not just its major radius.
- Boiler: main cylinder radius 0.55, body Y=0.20..1.92, 20 sides; upper cap
  radius 0.45 to Y=2.03; bands radius 0.575 at Y=0.30/1.75. Feet 0.16 x
  0.22 x 0.75, bevel 0.015; flue radius 0.105 to Y=2.32. Gauge outer/inner
  radii 0.11/0.092, 16 sides; needle radius 0.006. Full bounds above include
  the front wheel/gauge; bottom-centering shifts the cylinder along Z.
- `PALETTES['basement']`, linear RGB: plaster (0.25,0.255,0.23), tile
  (0.20,0.21,0.18), tile_worn (0.29,0.28,0.23), metal (0.16,0.19,0.18),
  rust (0.22,0.075,0.027), grime (0.075,0.09,0.065), floor (0.18,0.18,0.15),
  paint (0.26,0.06,0.028), gauge (0.58,0.55,0.40), glass (0.07,0.10,0.09;
  reserved, not assigned). Alpha 1. Metal metallic 0.65/roughness 0.58;
  other surfaces metallic 0/roughness 0.82.
- Shared bevels, geometry seeds, inspection lights, cameras, tolerances and
  budgets are in the School notes. No runtime tunables or dependencies added.

## Coordinator handoff

Preserve `basement_<surface>` slots and `bakeAxisConversion=false`. Unity must
create `.meta` files. Registration, material mapping, imported-object pivots,
rendering in fog/torchlight and missing-piece/missing-kit primitive fallback
remain the procedural/coordinator owner's checks. The offline validator is not
proof of scene wiring, native collision or artistic acceptance.
