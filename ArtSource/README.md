# ArtSource — 3D model authoring files

This folder holds the editable Blender (`.blend`) sources for project-made 3D models. It sits outside `Assets/`, so Unity never imports these files. Runtime content comes only from the exported FBX files and textures under `Assets/Art/`.

## Layout and naming

- `ArtSource/<Area>/<Asset>/` mirrors the export folder `Assets/Art/<Area>/<Asset>/`.
- Name each `.blend` after the asset it exports: `WORSEN_CakePickup.blend` exports `WORSEN_CakePickup.fbx`. Keep one asset per file, or one tightly coupled family that shares a rig (the blocky body and first-person arms).
- Do not use project-named or generic file names (`WORSEN.blend`, `untitled.blend`). Do not leave a `.blend` in the repository root or in `Assets/`, and do not keep one only under the ignored `Logs/` folder.
- Blender's `.blend1` save backups stay beside their source and are ignored by Git (`*.blend1`). Pre-change backups kept as evidence belong under `Logs/`, not here.
- Pack images into the `.blend` (**File › External Data › Pack Resources**) or keep texture sources in the same folder with relative paths. Do not reference absolute paths in `Logs/` or other checkouts.
- `*.blend` and `*.fbx` are stored with Git Large File Storage (LFS) according to [.gitattributes](../.gitattributes). Check that `git lfs ls-files` lists a new source once it is added.

## Adding or changing a model

1. Save the `.blend` at `ArtSource/<Area>/<Asset>/<AssetName>.blend` before modelling. In a connected Blender MCP session, check `bpy.data.filepath` first so work is not saved into another file.
2. Prefer a reproducible generator script in [tools/blender/](../tools/blender/README.md) that resolves repository-relative paths. For interactive work, record the steps or scripts in the provenance column.
3. Export FBX in metres at scale 1, Y up and −Z forward, with transforms applied. Export only runtime objects: no review cameras, lights, floors or archive collections.
4. Writing exports into `Assets/` triggers a Unity import, so hold the [Unity lease](../tools/coordination/README.md) for the checkout open in Unity. Otherwise stage the export under `Logs/AgentStaging/` and hand it off.
5. Put previews and validation evidence under `Logs/AgentValidation/Art/<Asset>/`.
6. Let Unity generate `.meta` files. Configure importer settings and material wiring through a deterministic editor setup tool (architecture §10), such as `BlockyCharacterSetup` or `HorrorArtSetup`.
7. Update the inventory above.

Use Blender 5.2 at `C:/Program Files/Blender Foundation/Blender 5.2/blender.exe`, headless with `--background --factory-startup --python-exit-code 1`. Blender 4.5 is also installed on this machine; do not use it for project art.
